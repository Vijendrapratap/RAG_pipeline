# How to Access the Transcript Search Dashboard on the Local Network

This guide is for anyone on the same Wi-Fi or LAN as the host PC who wants to
use the transcript search dashboard.

---

## Before You Start

- You must be on the **same network** as the host PC (same Wi-Fi router or
  wired LAN). It will not work over mobile data or a different network.
- You need the **password** — ask Vishvas for it.
- No software to install. You only need a web browser (Chrome, Firefox, Edge).

---

## Step 1 — Open Your Browser

On your PC, open any web browser.

---

## Step 2 — Go to the Dashboard

In the address bar, type exactly:

```
http://192.168.1.143:8080
```

Press **Enter**. If the page does not load, the host PC may be asleep or the
stack may not be running — let Vishvas know.

> **Note:** The IP address above is fixed to this network. If the host PC ever
> gets a new IP (rare), Vishvas will need to update this guide.

---

## Step 3 — Log In

You will see a password prompt. Enter the shared password and click **Sign in**.

---

## Step 4 — Type Your Query

In the search box at the top, type your question in plain English.

**Good examples:**
- *What did the speaker say about surrender?*
- *Explain the teaching on karma from the camp in 2019*
- *Find talks about meditation and the mind*

**Avoid keyword-only searches** — full questions get much better results.

Click the **Search** button or press **Enter**.

---

## Step 5 — Read the Results

Each result card shows:

| Field | What it means |
|---|---|
| **Score** | How relevant this passage is (higher = better match) |
| **Source** | The transcript file it came from |
| **Passage** | The exact text from the transcript |
| **Timestamp** | Where in the recording this passage appears |

The answer summary at the top is generated by the local AI model using the
retrieved passages.

---

## Step 6 — Filter Your Results (Optional)

Use the sidebar on the left to narrow results by:

- **Speaker / Track** — filter to a specific person or session type
- **Event / Season** — limit to a particular camp or year
- **Date range** — search within a specific time window

Apply filters before or after typing your query — the search reruns
automatically.

---

## Step 7 — Switch the Search Engine (Optional)

The **Engine** picker at the top lets you choose between:

| Engine | When to use it |
|---|---|
| **Hybrid** (default) | Best for most queries — combines keyword + semantic search |
| **PageIndex** | Better for broad thematic questions across many talks |

Leave it on **Hybrid** unless results feel off.

---

## Troubleshooting

| Problem | What to do |
|---|---|
| Page won't load | Check you are on the correct network; ask Vishvas if the stack is running |
| Password rejected | Double-check for typos; ask Vishvas to confirm the password |
| Results look irrelevant | Rephrase as a full question; try removing filters |
| Page loads but search hangs | Someone else may be querying at the same time — wait 30–60 seconds and try again |
| Very slow responses | The AI model is running locally on one GPU — response time is typically 20–60 seconds |

---

## What This System Is

All search and AI processing happens entirely on the host PC — nothing is sent
to the internet. The transcripts, the AI model, and the search index are all
stored locally.
